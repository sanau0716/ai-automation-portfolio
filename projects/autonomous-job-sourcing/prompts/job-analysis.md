# Job Analysis Prompt

The workflow uses AI to transform job-posting information into structured analysis that can support downstream routing.

When adapting this workflow, the AI analysis should consider:

- Role/title
- Responsibilities
- Required skills
- Preferred skills
- Experience requirements
- Employment type
- Location/remote requirements
- Candidate fit
- Potential concerns
- Overall recommendation

Keep the output structured and deterministic enough for downstream workflow logic.
